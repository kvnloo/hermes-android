z0 Agent is a clean, black-first chat client for a Hermes Agent server you run yourself.

• Stream replies with reasoning and tool calls as they happen
• Approve or deny agent actions right from the chat
• Attach photos, files and voice notes
• Theme engine: pick a preset or paste a theme as JSON, then share yours
• Subtle haptics for send, stop and finished turns
• Notifications when a turn finishes in the background

z0 Agent connects only to the server you choose. It has no account system, ads or tracking, and the developer never receives your chats.

z0 Agent is an independent fork of the open-source, MIT-licensed Ares app. It is not affiliated with or endorsed by Nous Research or the Ares authors.
