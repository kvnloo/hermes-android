# z0 Agent fork

This fork ships z0 Agent (`io.github.kvnloo.z0agent`), with a separate
debug application ID ending in `.dev`. The upstream README describes Ares,
not this fork's package, signer, builds, or release channels.

`main` mirrors upstream. Open fork changes against `staging`; Play
promotion and publishing are owner decisions. The NextGen theme engine and
ephemeral UI live on staging. See [the Android parity checklist](docs/PARITY_CHECKLIST.md)
for the current evidence and remaining device checks.
